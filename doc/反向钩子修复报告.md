## 2. 问题分析

### 2.1 EnNeuro 框架架构

EnNeuro 使用类似 PyTorch 的计算图机制：

```
Layer (Conv2d)
    ↓ 调用
Function.__call__(Conv2dFunction)
    ↓ 创建
output Tensor (包含 creator = Function)
    ↓ 反向传播
output.backward()
    ↓ 调用
Function.backward()
    ↓ 回传梯度
grad → input
```

### 2.2 根本原因

**反向钩子注册到 Layer，但反向传播是通过 Function 进行的**

1. **Layer** 负责前向传播，创建 **Function** 实例
2. **反向传播**是通过 **Function.backward** 进行的
3. 我们注册反向钩子到 **Layer**：`layer.register_backward_hook()`
4. 但 **Function.backward** 被调用时，不知道对应的 Layer

```python
# 问题：Layer 和 Function 是分离的
class Conv2d(Layer):
    def __call__(self, *inputs):
        # 创建 Function
        output = Conv2dFunction.apply(*inputs, self.weight, self.bias)
        return output

# 反向传播只涉及 Function，不涉及 Layer
class Conv2dFunction(Function):
    @staticmethod
    def backward(ctx, grad_output):
        # 这里无法触发 Layer 的反向钩子
        return grad_input, grad_weight, grad_bias
```

### 3.4 第四阶段：检查 HookRegistry 映射

创建 `HookRegistry` 全局注册表，建立 Function → Layer 映射：

```python
hook_registry = HookRegistry()

# 在 Layer.__call__ 中建立映射
def layer_call_with_hooks(self, *inputs):
    # ...
    outputs = original_layer_call(self, *inputs)

    # 建立映射：每个 Function → 当前 Layer
    for output in outputs:
        if hasattr(output, 'creator') and output.creator is not None:
            hook_registry.register_function_layer_mapping(output.creator, self)

    # ...
```

测试输出：
```
HookRegistry 映射:
- Function: ReLU, Layer: SimpleCNN
- Function: Conv2d, Layer: SimpleCNN
```

**问题发现**: 映射建立错误！ReLU 和 Conv2d Function 都映射到了外层的 SimpleCNN，而不是各自的 Layer。

### 3.5 第五阶段：修复映射逻辑

**问题原因**: 映射在 Layer.__call__ 中建立，但 Function 的创建发生在 `original_layer_call()` 内部。

**解决方案**: 使用 `HookRegistry._current_layer` 上下文变量，在 Layer 执行期间记录当前 Layer：

```python
hook_registry = HookRegistry()

def layer_call_with_hooks(self, *inputs):
    # 设置当前 Layer
    hook_registry.set_current_layer(self)

    outputs = original_layer_call(self, *inputs)

    # 清除当前 Layer
    hook_registry.set_current_layer(None)

    return outputs

def function_call_with_hooks(self, *inputs):
    # 获取当前 Layer 并建立映射
    current_layer = hook_registry.get_current_layer()
    if current_layer is not None:
        hook_registry.register_function_layer_mapping(self, current_layer)

    # ...
```

测试输出：
```
HookRegistry 映射:
- Function: ReLU, Layer: SimpleCNN  ✓ (因为 ReLU 在 SimpleCNN.__call__ 中创建)
- Function: Conv2d, Layer: Conv2d  ✓ (因为 Conv2d 在 Conv2d.__call__ 中创建)
```

## 4. 解决方案

### 4.1 核心设计

创建 **`HookRegistry`** 全局注册表：

```python
class HookRegistry:
    """全局钩子注册表 - 管理 Function 到 Layer 的映射"""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._function_to_layer = weakref.WeakKeyDictionary()
            cls._instance._current_layer = None
        return cls._instance

    def register_function_layer_mapping(self, function, layer):
        """注册 Function → Layer 映射"""
        self._function_to_layer[function] = weakref.ref(layer)

    def get_layer_for_function(self, function):
        """获取 Function 对应的 Layer"""
        if function in self._function_to_layer:
            return self._function_to_layer[function]()
        return None

    def set_current_layer(self, layer):
        """设置当前正在执行的 Layer"""
        self._current_layer = layer

    def get_current_layer(self):
        """获取当前 Layer"""
        return self._current_layer
```

### 4.2 修改 Layer.__call__


### 4.4 修改 Function.backward

```python
def function_backward_with_hooks(self, gy):
    # 执行原始反向传播
    grad_inputs = original_function_backward(self, gy)

    # 触发 Function 自身的反向钩子
    if hasattr(self, '_hook_manager') and self._hook_manager._backward_hooks:
        grad_outputs = (gy,) if not isinstance(gy, tuple) else gy
        self._hook_manager.trigger_backward_hooks(grad_inputs, grad_outputs)

    # 通过映射触发 Layer 的反向钩子
    layer = hook_registry.get_layer_for_function(self)
    if layer is not None and hasattr(layer, '_hook_manager') and layer._hook_manager._backward_hooks:
        grad_outputs = (gy,) if not isinstance(gy, tuple) else gy
        layer._hook_manager.trigger_backward_hooks(grad_inputs, grad_outputs)

    return grad_inputs
```

```python
def capture_features(layer):
    """捕获特征图"""
    storage = {'input': None, 'output': None}

    def hook(module, inputs, outputs):
        storage['input'] = [x.data.copy() if hasattr(x, 'data') else x for x in inputs]
        storage['output'] = outputs.data.copy() if hasattr(outputs, 'data') else outputs

    handle = layer.register_forward_hook(hook)
    return handle, storage


def capture_gradients(layer):
    """捕获梯度"""
    storage = {'grad_output': None, 'grad_input': None}

    def hook(grad_inputs, grad_outputs):
        if grad_outputs and len(grad_outputs) > 0 and grad_outputs[0] is not None:
            grad = grad_outputs[0]
            storage['grad_output'] = grad.data.copy() if hasattr(grad, 'data') else np.array(grad)

        if grad_inputs:
            storage['grad_input'] = [
                g.data.copy() if g is not None and hasattr(g, 'data') else None
                for g in grad_inputs
            ]

    handle = layer.register_backward_hook(hook)
    return handle, storage
```

## 7. 技术要点总结

### 7.1 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 映射存储方式 | WeakKeyDictionary | 避免循环引用，自动清理 |
| Layer 追踪方式 | _current_layer 上下文变量 | 解决嵌套 Layer 问题 |
| 钩子触发时机 | Function.backward 内部 | 与反向传播同步 |

### 7.2 避免的陷阱

1. ❌ **不要在 Layer.__call__ 中直接建立映射**
   - 原因：Function 在 `original_layer_call()` 内部创建
   - 解决：使用 `_current_layer` 上下文变量

2. ❌ **不要使用强引用存储 Layer**
   - 原因：会造成循环引用，内存泄漏
   - 解决：使用 `weakref.ref()` 弱引用

3. ❌ **不要在反向传播前触发钩子**
   - 原因：梯度还不存在
   - 解决：在 `original_function_backward()` 之后触发

### 7.3 代码复用性

修复后的设计完全符合 EnNeuro 的工程规范：

- ✅ 使用现有的 `HookManager` 管理钩子
- ✅ 使用现有的 `HookHandle` 管理生命周期
- ✅ 提供 `capture_features()` 和 `capture_gradients()` 便捷函数
- ✅ GradCAM 完全依赖 hooks 模块，不自己实现钩子逻辑
